Project introduction · Danio rerio, larval brain

A foundation model of the zebrafish brain

One model that joins what each cell expresses, where cells sit in the brain, and what happens when a gene is removed.

Status: a plan. No real data are downloaded and there are no results about zebrafish. The environment installs, the stage 0 inventory runs, and the smallest model has been trained once on synthetic cells as a smoke test.

Genes join the three layers

The three kinds of public data do not share cells or animals. They share genes. So the gene identifier is the key that joins them, and the model is built and tested around it.

Why this is hard

  • Scale. The two largest atlases here hold about 710,000 cells together. Geneformer was pretrained on about 30 million and later more than 100 million. Whether a zebrafish-only model deserves the name "foundation model" is a question for the tests.
  • Stage mismatch. Daniocell ends at 120 hpf. The mapzebrain reference is at 6 dpf, which is 144 hpf. Cells and atlas must be matched by stage, or the mismatch measured.
  • No shared cells. No cell has both a transcriptome and a position. Every link from a cell to a region is an inference through marker genes.
  • Gene identifiers. Zebrafish has many duplicated genes. Reusing a model trained on human cells needs an ortholog map, and that map is many-to-many.
  • Licences. The reuse terms of each source are not checked yet.

Stages

Each stage has a simple baseline. If the baseline wins, the stage reports that.

  1. Stage 0

    Inventory

    Download terms, file formats, genome build, gene identifiers. One row per data set in the manifest.

  2. Stage 1

    Cell encoder

    Genes ranked by expression in each cell, read by a small transformer.

    Test: cell type and stage on held-out animals and data sets. Baseline: principal components with a linear classifier.

  3. Stage 2

    Cells into the brain

    Predict the region of a cell from its expression, through the marker gene maps.

    Test: cell types with known positions. Null: random marker sets of the same size.

  4. Stage 3

    Functional genomics

    Remove a gene in the model and predict which regions change.

    Test: the 132 mutants, predicted regions against measured maps. Null: expression-matched random genes.

  5. Stage 4

    Image encoder

    A 3D vision transformer for registered brain stacks, in the manner of BrainIAC. Its test is set after stage 2.

Neuro-Workflow as the main architecture

Neuro-Workflow, from the Neural Computation Unit at OIST, organizes brain modelling as a graph of nodes. Each node carries a schema of its role, inputs, outputs and parameters, so people and AI agents can both connect it. In this project every step is a node and every stage is a workflow.

Project stageNodes
0 InventoryManifest loader, manifest check. Both are written and run.
1 Cell encoderAtlas loader, rank tokenizer, encoder training, held-out classifier, baseline classifier
2 Cells into the brainRegion atlas loader, marker map loader, region predictor, random marker null
3 Functional genomicsMutant map loader, gene removal, region comparison, matched random gene null
LaterRegion wiring to a TVB connectome, whole-brain simulation, comparison with measured activity maps
  • No stage for machine learning yet. Neuro-Workflow's nine stages cover simulation. Tokenizing and training need new stage names, to be agreed with its maintainers.
  • Long GPU runs inside a node are untried. A training node should launch a job and return a checkpoint path, not hold a model in a port.
  • Licence. Neuro-Workflow is under PolyForm Noncommercial 1.0.0. This project installs it and copies none of its code.

GPU use and scale

No timing has been measured, so no GPU-hour estimate is given. The sizes below are arithmetic from stated assumptions: a gene vocabulary of about 30,000 and up to 2,048 tokens per cell, which gives up to 1.45 billion tokens per pass over 710,000 cells.

TierDataModelHardwareGo on when
S10,000 cells4 layers, width 128, about 5 M weightsLaptop, no GPUEvery node and test runs end to end
MAll zebrafish cells6 layers, width 256, about 12 MOne GPUIt beats the baseline on held-out animals, and the permuted-label run fails
LZebrafish plus other species through orthologs12 layers, width 512, about 53 MSeveral GPUs or a clusterTier M has passed and the ortholog map is validated
  • Set a GPU-hour ceiling for each stage before its first run, and record every run, failed ones included, in a ledger.
  • Time a short run first. If the projected total exceeds the ceiling, the full run does not start.
  • Check the output of a run before recording it as done.
  • Stage 3 runs 2,772 gene screens: 132 mutated genes, each with 20 matched random genes.

First measurement

The smallest model was trained on synthetic cells, random type profiles plus noise, to check that the nodes run and to get a first timing. It says nothing about zebrafish.

  • The model beats both baselines on held-out cells, by a small margin.
  • The first attempt, at 600 steps, projected 394 s against the 360 s ceiling and did not start. The ceiling was kept and the steps halved.
  • At this speed, one pass over 1.45 billion tokens with this model would take about 3.7 hours on this GPU. That is arithmetic from one short run.

Setup

The dependency list resolves and the stage 0 workflow runs. The full install, downloading and training are untested.

git clone https://github.com/Kays3/geneformer-vs-brainiac.git
cd geneformer-vs-brainiac/zebrafish-brain-fm
uv sync
uv run python workflows/stage0_inventory.py
  • No data in git. Each download gets a path, a sha256 and a licence in data/MANIFEST.tsv.
  • A data set with an empty licence cell is not used.
  • The laptop is for writing and small checks. Training needs a GPU machine, and its cost is estimated from a short timed run first.

Decisions still open

  • Train from scratch on zebrafish, adapt a model from other species through orthologs, or do both and compare.
  • One larval stage only, or development as well.
  • Which reference space is the standard: mapzebrain or Z-Brain.
  • Where training runs, and how much compute stage 1 may use.
